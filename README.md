# 📚 Book Review Website

A modern, fast, and responsive book review platform built using **HTML**, **CSS**, **JavaScript**, and **Vite**. Users can browse books, see ratings, read summaries, and explore details — all through a clean and interactive interface.

---

## 🌟 Features

- 🔍 Browse a list of books  
- 📖 View detailed book information  
- ⭐ Display user ratings & reviews  
- ⚡ Fast development & build powered by Vite  
- 🎨 Clean and responsive UI  

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| **Frontend** | HTML, CSS, JavaScript |
| **Tooling** | Vite |
| **Data** | Local JSON / mock API |
